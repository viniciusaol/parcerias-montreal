# Parcerias Montreal

Apresentação estática em 15 telas. Abra `index.html` para revisar localmente. Os arquivos de imagem e fonte ficam em `assets/`.

## Publicação

O [repositório da apresentação](https://github.com/viniciusaol/parcerias-montreal) publica [parcerias.montrealtenis.com.br](https://parcerias.montrealtenis.com.br/) pelo GitHub Pages a partir da raiz da branch `main`.

O domínio personalizado está registrado no arquivo `CNAME` e em **Settings → Pages → Custom domain**. A zona DNS na HostGator usa este apontamento.

| Tipo | Nome | Destino |
| --- | --- | --- |
| CNAME | `parcerias` | `viniciusaol.github.io` |

[Configuração de domínio personalizado no GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)
